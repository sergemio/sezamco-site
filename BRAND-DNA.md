# Sezam&Co — Brand Identity (valide 10/03/2026)

## Identite
- **Nom** : Sezam&Co (ecrit colle, avec &) — logo : "Sezam&Co"
- **Tagline** : Street food libanaise
- **Positionnement** : street food libanaise authentique, moderne, accessible
- **Vibe** : chaleureux, decontracte, genereux, sans chichi — comme manger dans la rue a Beyrouth mais a Lyon
- **Ce qu'on n'est PAS** : fin dining, chic, formel, fusion, "healthy bowl"

---

## Direction visuelle — "Beirut street market meets editorial food magazine"

### Inspirations
- **Z&Co (zandco.es)** : grid asymetrique, editorial, structure propre, "Fun Lebanese Facts", marquee scrollant, clean et premium
- **Chikin Bang (chikinbang.com)** : energie, audace, blocs colores pour livraison, bandes marquee avec rythme, immersion totale
- **On prend** : la structure editoriale de Z&Co + l'energie/rythme de Chikin Bang
- **On ne prend PAS** : le dark green total de Z&Co, ni le neon de Chikin Bang

### Principes cles
1. **Fonds pastels dominants** — creme, vert pastel, jaune doux. C'est l'ADN Sezam.
2. **Accents forts en ponctuation** — vert profond pour titres, corail pour CTAs. Jamais en fond de section entiere.
3. **Grid asymetrique** pour les photos food — PAS de cartes identiques alignees
4. **Marquee bands** entre sections ("MAN'OUCHE — SHAWARMA — FALAFEL — LYON 2") pour le rythme
5. **Espace genereux** — le pastel + espace blanc = respiration. On ne surcharge pas.
6. **Elements decoratifs subtils** — petits SVG (olives, feuilles, grains de sesame) en filigrane
7. **Blocs colores** pour la section livraison (inspire Chikin Bang, adapte palette Sezam)

## Structure homepage (ordre valide)

1. **Hero** — Photo plein ecran + titre Ambery massif + 1 ligne sous-titre + CTA. PAS de paragraphe.
2. **Best-sellers** — Grid asymetrique, 4-5 plats phares (photo + nom + prix)
3. **Tradi ou Urbain ?** — Categories man'ouches (concept existant, mieux execute)
4. **La Formule** — Prix + contenu + CTA
5. **Livraison** — Blocs colores (commande directe, Uber, Deliveroo, Delicity)
6. **Avis Google** — Note + 3 avis
7. **Footer** — Contact, adresse, reseaux, liens SEO

### Marquee bands
- Entre sections, texte scrollant horizontal : noms de plats, keywords
- Style : fond vert profond ou corail, texte Ambery blanc/jaune

## Halal — Strategie
- **Present dans** : meta description, schema JSON-LD, texte footer SEO, page FAQ
- **Absent de** : hero, titres, marquee, visuels prominents
- **Logique** : trouvable si on cherche, pas pousse en avant (refroidit certains clients)

---

## SEO — Acquis a preserver
- Structure Hn optimisee (H1 avec keyword principal)
- Meta title / description par page
- Schema JSON-LD Restaurant
- Maillage interne vers pages produit (/shawarma-lyon, /falafel-lyon, /manouche-lyon)
- Open Graph
- Footer SEO avec liens geolocaux
- Pages produit = pages separees, PAS sur la homepage
